# Lauren Elbert Portfolio

A minimalist, responsive portfolio built with plain HTML and CSS.

## Preview

Open `index.html` in a browser, or run a local static server from this folder (for example, `npx serve .`) and visit the local address it prints. The projects page is `projects.html`.

## Updating the site

- Edit the home page in `index.html` and project details in `projects.html`.
- Shared styling is in `home/home.css`.
- Replace each `.image-placeholder` block with an image when your project images are ready. Keep image descriptions accessible with useful `alt` text.
- Contact details and social links are ordinary links in the HTML and can be updated there.
